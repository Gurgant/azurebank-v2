# The American forms that stay, for infra/check_british_spelling.py.
#
# A line is "word | file | text on the line | reason".
#   word              the word as it is written, in its exact letter case
#   file              the path from the root of the repository; * stands for any run of characters
#   text on the line  a text that the same line of the file holds, or * for any line
#   reason            why the word is not mine to respell, in one line
#
# A name inside backticks, a fenced block, a link's address or an HTML attribute needs no line
# here: the check does not read those. That is why "Authorization", "color" and "Program.cs" are
# not below. A line that allows nothing fails the check: delete it when its word is gone.
